Finding the best way to install on your device…

Other devices

Android phone or tablet
  1. Open this page in Chrome.
  2. Tap Install Nexora (or the menu ⋮ → Install app).
  3. Open Nexora from your home screen.
iPhone or iPad
  1. Open this page in Safari (not Chrome).
  2. Tap the Share button (square with an arrow).
  3. Tap Add to Home Screen, then Add.
Windows computer
  1. Download Nexora-Setup.exe (35 KB) and open it.
  2. If Windows says "protected your PC", click More info → Run anyway. (It is not signed because certificates cost money.)
  3. Nexora appears on your Desktop and Start menu.

Or in Edge/Chrome: click the install icon at the right of the address bar.

Mac
  1. Safari: menu File → Add to Dock.
  2. Chrome / Edge: click the install icon at the right of the address bar.
Linux
  1. Chrome / Chromium / Edge: click the install icon in the address bar.
  2. Or download install-linux.sh and run sh install-linux.sh.
Smart TV, Fire TV, Android TV
  1. Open the TV's web browser and type this page's address.
  2. Nexora switches to TV mode (big text, remote-friendly) by itself.
  3. Or play on your phone, tap Connect and pick the TV.

Apple TV has no browser: play on your iPhone and use AirPlay.
